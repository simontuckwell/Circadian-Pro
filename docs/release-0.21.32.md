# Circadian Pro 0.21.32

Documentation update following acceptance into the HACS default catalog on 4 November 2026.

- Lead the README with searching for Circadian Pro in HACS; keep adding a custom repository as a fallback.
- Explain the one-time integration setup, automatic administrator sidebar panel and first profile in English and Spanish.
- Clarify manual installation, existing installations, updates and the optional light preview.
- Link to the official HACS/Marketplace guidance and distinguish the installation routes for different Home Assistant versions.
- Keep the release procedure aligned with catalog inclusion and the Node.js version already pinned in CI.

Lighting logic, the panel, translations, configuration, calibrations and entity identifiers are unchanged from 0.21.31. Within the installable component, only the manifest version changes. Existing users can continue using 0.21.31; this release does not require a configuration migration.

Validation and publication evidence are recorded with the GitHub release. This documentation update does not include a new Home Assistant installation, physical-light test or live Marketplace compatibility check.
